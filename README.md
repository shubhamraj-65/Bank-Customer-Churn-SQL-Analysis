# 🏦 Bank Customer Churn SQL Analysis

## 📌 Project Overview

This project focuses on analyzing customer churn in the banking sector using **MySQL**.

The objective is to understand customer characteristics, identify potential churn patterns, and generate data-driven insights that can help a bank improve customer retention.

The analysis is being performed using a bank customer churn dataset containing **10,000 customer records and 14 attributes**.

---

## 🎯 Business Problem

The key business questions addressed in this project are:

* Why are customers leaving the bank?
* Which customer segments have higher churn risk?
* How does customer activity relate to churn?
* How do geography, age, credit score, balance, and number of products relate to customers?
* Which customer groups could be targeted for better retention?

---

## 🗂️ Dataset

The dataset contains customer-level information such as:

| Column          | Description                     |
| --------------- | ------------------------------- |
| CustomerId      | Unique customer identifier      |
| Surname         | Customer surname                |
| CreditScore     | Customer credit score           |
| Geography       | Customer location               |
| Gender          | Customer gender                 |
| Age             | Customer age                    |
| Tenure          | Number of years with the bank   |
| Balance         | Customer account balance        |
| NumOfProducts   | Number of banking products used |
| HasCrCard       | Credit card ownership status    |
| IsActiveMember  | Customer activity status        |
| EstimatedSalary | Estimated customer salary       |
| Exited          | Customer churn status           |
